# Корпоративный сервис микроблогов (Twitter Clone)

Бэкенд корпоративного сервиса микроблогов на FastAPI и PostgreSQL.

## Стек технологий
* **Язык**: Python 3.11
* **Фреймворк**: FastAPI
* **ORM**: SQLAlchemy 2.0 (асинхронный драйвер asyncpg)
* **Схемы и валидация**: Pydantic v2, pydantic-settings
* **База данных**: PostgreSQL 15
* **Веб-сервер / Reverse Proxy**: Nginx (Alpine)
* **Тестирование**: pytest, pytest-asyncio, httpx, aiosqlite
* **Контейнеризация**: Docker, Docker Compose

## Локальный запуск тестов
Для запуска интеграционных и модульных тестов выполните в терминале:
```bash
pytest -v
```

## Развертывание через Docker Compose

Для сборки и запуска всего стека (PostgreSQL, FastAPI, Nginx) выполните команду:
```bash
docker-compose up -d --build
```

## Доступ к сервисам и Swagger

После успешного старта контейнеров сервис доступен по следующим адресам:

* **Веб-интерфейс приложения**: http://localhost (порт 80)
* **Интерактивная документация Swagger UI**: http://localhost/api/docs
* **Альтернативная документация ReDoc**: http://localhost/api/redoc

## Сценарий быстрой проверки API через Swagger UI

Для интерактивного тестирования откройте документацию по адресу [http://localhost/api/docs](http://localhost/api/docs).

### Пошаговый сценарий

#### Шаг 1. Проверка профиля
* **Эндпоинт:** `GET /api/users/me`
* Нажмите **Try it out** $\to$ Введите токен авторизации пользователя: **test** $\to$ **Execute**.
* **Ожидаемый результат:** Статус `200 OK` с данными пользователя Andrei Zaharov и списками его подписок (`following`) и подписчиков (`followers`).

#### Шаг 2. Загрузка изображения к твиту
* **Эндпоинт:** `POST /api/medias`
* Нажмите **Try it out**, введите токен авторизации пользователя (**test**) и выберите любое изображение на компьютере в поле `file` и нажмите **Execute**.
* **Ожидаемый результат:** Статус `201 Created`, в теле ответа возвращается `media_id` (например, `1`). Скопируйте этот ID.

#### Шаг 3. Публикация твита
* **Эндпоинт:** `POST /api/tweets`
* Нажмите **Try it out** и отправьте JSON с текстом и скопированным ID картинки:
  ```json
  {
    "tweet_data": "Тестируем микросервис через Swagger!",
    "tweet_media_ids": [1]
  }
  
#### Шаг 4. Отметка «Нравится» от другого пользователя
* **Эндпоинт:** `POST /api/tweets/{tweet_id}/likes`
* Нажмите кнопку **Try it out** укажите токен авторизации пользователя (**vasya_key**), укажите **tweet_id:** 3 (ID созданного твита) и нажмите Execute.
*  **Ожидаемый результат:** Статус 200 OK и ```{"result": true} ```. Твит получил лайк от Vasya Smith.

#### Шаг 5. Проверка сортировки ленты
* **Эндпоинт:** `GET /api/tweets`
* Нажмите **Try it out** $\to$ Введите токен авторизации пользователя: **test** $\to$ **Execute**.
*  **Ожидаемый результат:** Статус 200 OK. В списке tweets возвращаются публикации автора и пользователей, на которых он подписан, строго отсортированные по популярности (количеству лайков в порядке убывания). Созданный твит будет в топе ленты.

#### Шаг 6. Проверка прав на удаление (проверка авторизации)
* **Эндпоинт:** `DELETE /api/tweets/3`
* Находясь под токеном vasya_key, попробуйте удалить твит Андрея:
* **Ожидаемый результат:** 403 Forbidden ```"error_message": "Вы не можете удалить чужой твит"```.
* Смените токен на test и повторите запрос `DELETE /api/tweets/3`
* **Ожидаемый результат:** Статус 200 OK и ```{"result": true}```
